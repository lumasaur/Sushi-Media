## Decisions Made

**1. Combined Tasks 1 & 2 into single commit**
- Both tasks modify only lib/slides/content.ts (data changes)
- Atomic commit ensures data consistency
- Rollback guidance accommodates both approaches

**2. Slide 10 uses 'cta' layout (not 'centered')**
- Plan specified 'centered' but CenteredMinimal component lacks CTA button support
- CenteredMinimal designed for headline + subtext only
- Existing 'cta' layout provides proper CTA button rendering
- Premium dark background maintained for visual impact

**3. Added 40-60 split ratio to AsymmetricSplit**
- Plan specified 40-60 for slides 4 and 6
- Original component only supported 60-40, 70-30, 50-50
- Extended interface and grid templates to support 40-60
- Enables more content-focused layouts (smaller image, larger content area)

**4. Integrated mini-story links into AsymmetricSplit component**
- Plan mentioned "Add mini-story link to AsymmetricSplit" in Task 3
- Implemented as component prop + conditional rendering
- Consistent styling with kincha accent and arrow icon
- Cleaner than separate rendering in page.tsx

**5. Fixed textPosition types across mini-story files**
- TypeScript errors revealed type mismatch
- Mini-story interfaces defined 'center' | 'left' | 'right'
- FullBleedHero expects 'center' | 'bottom-left' | 'bottom-center'
- Aligned all interfaces to match FullBleedHero (Rule 3 - Blocking)
