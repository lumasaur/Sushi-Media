# Modern Presentation Design Research (2024-2026)

**Research Date:** January 28, 2026
**Project:** Ami Sushi Premium Web Presentation
**Primary Target:** iPad Landscape (1024px)

---

## Executive Summary

This research document compiles modern presentation design trends, best practices, and technical considerations for creating a premium web-based presentation for Ami Sushi. The findings emphasize minimalism, strategic use of whitespace, bold typography, and sophisticated color application while maintaining accessibility and performance.

**Key Trends Identified:**
- Dark mode with high-contrast accents
- Bold, oversized typography as primary visual element
- Minimalist layouts with purposeful whitespace
- Interactive and non-linear presentation structures
- Story-driven design with clear narrative arcs
- Japanese aesthetic principles (ma, wabi-sabi, shibumi)

## 1. Modern Presentation Design Trends (2024-2026)

### 1.1 Dominant Visual Trends

#### Dark Mode with High Contrast
Dark mode is now the dominant choice in premium presentations, featuring high-contrast neon accents (lime green, electric blue) on deep charcoal or black backgrounds. This approach:
- Reduces eye strain on modern LED screens
- Makes accent colors pop dramatically
- Conveys sophistication and modernity
- Works exceptionally well in both bright and dim environments

**Source:** [SlidesAI Blog - 35 Presentation Design Trends](https://www.slidesai.io/blog/presentation-design-trends)

#### Bold Typography as Visual Element
Typography has evolved from supporting element to main visual component:
- 300% spike in downloads for decks using massive, bold, sans-serif fonts
- Titles taking up 50% of screen space
- Large text functioning as design element (fading into background, transparent overlays, behind images)
- Creates immediate visual hierarchy and grabs attention

#### Minimalism with Purpose
Modern minimalism focuses on "logical simplicity" rather than just "less is more":
- Each element serves a specific purpose
- Ruthless editing of content
- Strategic use of whitespace to create breathing room
- Increased perceived quality through clean, uncluttered design

## 2. Visual Layout Patterns

### 2.1 Split Screen Layouts

#### Asymmetric Split Screen Design
Split screen layouts are a growing trend in 2024 presentations and web design:

**Key Characteristics:**
- Uneven splits (e.g., 60/40 or 70/30) give extra weight to one side
- Directs user attention toward the weighted panel
- Creates visual interest and breaks monotony
- Excellent for quickly grabbing attention and highlighting key information

**Variations:**
1. **Classic Asymmetric:** Vertical split with one side larger (usually left)
2. **Diagonal Division:** Using diagonal lines to introduce asymmetry
3. **Layering Splits:** Elements from one screen overlapping the other

**Use Cases for Ami Sushi:**
- Dish photography on one side, description on the other
- Chef profile with action photography
- Menu section showcasing with complementary imagery

**Sources:**

### 2.2 Full-Bleed Imagery

#### What is Full Bleed?
Images that cover the complete slide canvas with no boundary or blank spaces, extending from edge to edge.

**Benefits:**
- Creates powerful, attention-grabbing effect
- Images feel "larger than life"
- Evokes feelings of grandeur or intimacy
- Removes barriers and invites audience into the story

**Best Practices:**
1. **Image Quality:** Use high-resolution images that won't pixelate when stretched
2. **Text Placement:** Find solid space in photo where text won't be interrupted
3. **Contrast:** Ensure sufficient contrast between text and background
4. **Enhancement Techniques:**
   - Add subtle drop shadow to text
   - Use subtle color overlays for better text legibility
   - Darken or lighten areas of image for text placement

**Alternative Approach:**
- **Partial Bleed:** Image touches 2-3 edges instead of all 4
- Creates professional impact while leaving space for text
- Less demanding on image quality

**Design Principle:** "Bleed at least a little, somewhere" - bleeding to at least one edge looks more professional than contained images.

**Recommendation for Ami Sushi:** Use full-bleed for hero slides showcasing signature dishes, partial bleed for informational slides with more text content.

### 2.3 Card-Based vs. Grid Layouts

#### Card-Based Design (2024-2025)
Card UI is "making all the noise in 2025" with adoption by industry leaders (Salesforce, Apple, Pinterest):

**Key Characteristics:**
- Information presented in digestible chunks
- Quick comprehension and scanning
- Responsive grid systems
- Entire card acts as clickable element

**Best Practices:**
1. **Consistent Spacing:** Use 4px grid system for padding/margins
2. **Responsive Adaptation:** 3 cards on desktop, 1 on mobile
3. **Interactive Elements:** Hover effects, shadow shifts, subtle animations
4. **Visual Organization:** Uniform containers in responsive grid

**Bento Grid Design (2025 Trend):**
- Modular system inspired by Japanese bento boxes
- Popularized by Apple, Notion, Framer
- Asymmetric module sizes within grid
- Clean, scroll-friendly, highly visual
- Each "card" showcases distinct content

**Use Cases for Ami Sushi:**
- Menu category overview (different card sizes for different courses)
- Chef team introduction
- Location/ambiance showcase
- Signature dish highlights

**Recommendation:** Hybrid approach - use Bento grid for overview slides, full-bleed for hero moments.

### 2.4 Whitespace and Visual Hierarchy

#### Strategic Whitespace Usage
Whitespace (negative space) is critical for modern presentation design:

**Benefits:**
- Reduces clutter and increases readability
- Creates focus points by surrounding key content
- Increases perceived quality and premium feel
- Provides breathing room for content
- Enhances visual appeal through balanced composition

**Modern Trends:**
- Minimalist layouts championing simplicity
- Grouping related items with generous spacing
- Centered layouts with expansive margins
- Single focal point per slide

**Typography and Whitespace:**
- Bold colors and whitespace grab attention
- Uncluttered typography highlights key ideas
- Large text with generous spacing around it
- Quote slides: centered quote with lots of whitespace

**Recommendation for Ami Sushi:** Embrace generous whitespace to convey premium positioning and allow beautiful photography to breathe.

### 2.5 Creative Typography Treatments

#### Oversized Typography
Typography as primary design element:

**Trends:**
- Massive titles taking up 50%+ of screen
- Typography fading into background
- Text behind images as layered element
- Transparent overlays creating depth
- Bold, sans-serif fonts dominating

**Typography Hierarchy:**
- Size and weight establish importance
- Contrast creates visual flow
- Placement guides eye movement

**Font Selection Guidelines:**
- Avoid more than 2-3 font families
- Use font weight variations for hierarchy
- Ensure sufficient line height (1.5-2x font size)
- Minimum 18px for body text, 36px+ for headlines

**Recommendation for Ami Sushi:** Use bold Japanese-inspired typography for headers, clean sans-serif for body text, generous sizing throughout.

## 3. Color Usage Best Practices

### 3.1 Accent Colors Strategy

#### Purpose and Application
Accent colors should be used sparingly and strategically:

**Core Principle:** "If everything uses the accent color, nothing is urgent"

**Recommended Approach:**
- Use accents to highlight important points, callouts, key data
- 1-2 accent colors maximum
- Apply consistently throughout presentation
- Reserve for CTAs, badges, emphasis elements

**Palette Structure:**
- **3-5 colors total** for clean, consistent design
- **Base color:** Headers and backgrounds
- **Accent color:** CTAs, highlights, emphasis
- **Neutral color:** Body text, secondary elements

**Business Presentation Best Practices:**
- Neutral backgrounds paired with blue, green, or teal accents
- These colors feel calm, trustworthy, easy to read
- Ideal for client and investor presentations

**Warm Accent Colors:**
- Yellow: Cheerfulness, accessibility, energy, affordability
- Gold: Sophistication, premium positioning
- Use as highlights, not primary colors

**Strategic Considerations:**
- Keep accents subtle and consistent
- When in doubt, stick to neutrals with 1-2 flexible accents
- Consider global/cultural color associations

**Recommendation for Ami Sushi:**
- Primary: Deep navy or charcoal (traditional, sophisticated)
- Accent: Warm coral/salmon (sushi-inspired, inviting)
- Secondary accent: Gold (premium, celebratory)
- Neutrals: Cream, warm white

### 3.3 Background Color Strategies

#### Dark vs. Light Backgrounds

**Dark Backgrounds:**
- Modern, sophisticated appearance
- Better for dim environments
- Makes colors pop dramatically
- Reduces eye strain on LED screens
- Light text requires careful contrast management

**Light/Neutral Backgrounds:**
- Classic, clean appearance
- Better for bright environments
- Easier to maintain accessibility
- Better for printing/PDF versions
- More versatile for various content types

**Gradient Backgrounds:**
- Add depth and sophistication
- Create visual interest without overwhelming content
- Linear gradients for backgrounds/section transitions
- Radial gradients for spotlight effects

**Gradient Best Practices:**
1. **Keep It Subtle:** Avoid overwhelming audience
2. **Limit Colors:** 2-3 colors maximum in gradient
3. **Text Placement:** Place light text on darker gradient sections
4. **Consistency:** Maintain consistent gradient style throughout
5. **Selective Application:** Use for backgrounds, shapes, not every element

**Image Backgrounds:**
- Full-bleed photography for hero slides
- Requires careful text overlay treatment
- Always ensure sufficient text contrast

**Recommendation for Ami Sushi:**
- Hero slides: Full-bleed photography with subtle dark overlay for text
- Content slides: Cream/warm neutral backgrounds
- Section dividers: Deep navy with gold accents
- Interactive elements: Subtle gradients for depth

## 4. Image Integration

### 4.1 Photography Best Practices

#### Food Photography for Premium Presentation

**Why It Matters:**
Studies show restaurants using professional food photography see an average 30% increase in item engagement compared to text-only presentations.

**Key Techniques:**

**Lighting:**
- Natural light preferred for food photography
- Soft, diffused lighting to avoid harsh shadows
- Side lighting to create depth and dimension
- Overhead lighting for flat lay compositions

**Angles:**
- **Overhead (90°):** Best for flat compositions, multiple dishes, geometric plating
- **45° Angle:** Most natural viewing angle, shows depth and layers
- **Straight-on (0°):** Emphasizes height, perfect for burgers, cakes, stacked dishes

**For Sushi Specifically:**
- Overhead shots showcase arrangement and variety
- 45° angle shows fish texture and rice structure
- Close-ups highlight quality and freshness
- Clean, minimalist plating photographs best

**Camera Settings (Technical):**
- Wide aperture (f/2.8-f/4) for individual dishes (beautiful background blur)
- Narrower aperture (f/8-f/11) for overhead shots of multiple dishes
- Fast shutter speed to freeze steam or motion

### 4.3 Image + Text Composition

#### Overlaying Text on Photography

**Core Challenge:** Achieving visual harmony between image and text while maintaining readability.

**Key Techniques:**

**1. Color and Gradient Overlays**
- Dark overlay provides instant legibility boost
- Typical overlay: 30-50% opacity black
- Gradient overlays create mood while improving readability
- Balance transparency so image shows through

**2. Contrast Strategies**
- Strong contrast between text and image essential
- Light text over dark images (or vice versa)
- Use WebAIM Contrast Checker to verify WCAG compliance
- Minimum 4.5:1 contrast ratio for normal text

**3. Layering and Shapes**
- Add solid or transparent shapes behind text
- Maintains important photo elements
- Creates clear text zones
- Can use brand colors for shapes

**4. Image Blur Technique**
- Blur portions of image where text will appear
- One of easiest techniques for readability
- Maintains visual connection to image
- Selective blur keeps focus on important elements

**5. Composition Principles**
- Find solid space in photo for text placement
- Look for areas with minimal action/detail
- Use rule of thirds for text placement
- Consider natural eye flow through image

**Best Practices:**
- "Keep it simple" - see both photo and words
- Add subtle drop shadow to text (improves separation)
- Test in projection environment, not just on screen
- Use built-in tools to enhance contrast if needed
- Every slide is a composition - arrange elements cohesively

**Recommendation for Ami Sushi:**
- Use subtle dark gradients (top or bottom) for text zones
- Place text in naturally calm areas of photography
- Maintain 4.5:1+ contrast ratio for accessibility
- White text with subtle shadow on food photography
- Reserve full overlays for hero/title slides only

### 4.4 Full-Bleed vs. Contained Images

#### When to Use Each Approach

**Full-Bleed Images:**
- **Best For:**
  - Hero/title slides
  - Establishing mood and atmosphere
  - Showcasing signature dishes
  - Section dividers
  - Maximum visual impact moments

- **Advantages:**
  - Immersive, attention-grabbing
  - Conveys luxury and premium quality
  - Removes barriers between viewer and content
  - Creates emotional connection

- **Challenges:**
  - Requires high-quality, high-resolution images
  - Text placement more difficult
  - May need overlay/treatment for readability

**Contained Images:**
- **Best For:**
  - Multiple images on same slide
  - Image galleries or comparisons
  - Text-heavy slides with supporting imagery
  - Technical/informational content

- **Advantages:**
  - Easier to balance with text
  - More flexible layouts
  - Works with varied image qualities
  - Clear visual boundaries

- **Challenges:**
  - Can feel less premium if not designed well
  - Requires thoughtful spacing and alignment
  - May appear dated if poorly executed

**Partial Bleed (Hybrid):**
- Image touches 2-3 edges instead of all 4
- Creates professional impact with flexibility
- Leaves space for text without overlay
- Good compromise for varied content

**Design Principle:** "It's often better to have one large, powerful image rather than several smaller images on the same slide."

**Recommendation for Ami Sushi:**
- **Full-bleed:** Opening slide, chef portrait, signature dish showcases, location ambiance
- **Contained:** Menu overview with multiple items, team photos, process/behind-scenes
- **Partial bleed:** Informational slides about ingredients, sourcing, philosophy

### 7.1 Responsive Design for iPad Landscape (1024px)

#### iPad Landscape Resolution Standards
- **Primary Resolution:** 1024x768px (landscape orientation)
- **Portrait:** 768x1024px
- **Development Rendering:** 768px (portrait) and 1024px (landscape)

**Critical Breakpoint:**
1024px is described as a "critical threshold where designs transition from tablet/mobile layouts to desktop-like experiences."

**Design Characteristics at 1024px:**
- Takes on desktop design properties vs. mobile
- Suitable for three-column layouts
- More horizontal content display
- Larger tablets in landscape mode
- iPad in landscape as primary use case

**Source:** [BrowserStack - Breakpoints for Responsive Web Design](https://www.browserstack.com/guide/responsive-design-breakpoints)

#### Responsive Design Breakpoints

**Standard Breakpoint Values:**
- **480px:** Mobile phones (portrait)
- **768px:** Tablets (portrait) and large phones (landscape)
- **1024px:** iPad landscape, large tablets
- **1280px:** Laptops and small desktops

**Best Practices:**
- Design mobile-first, then enhance for larger screens
- Test at each major breakpoint
- Ensure touch targets are 44px minimum for tablet
- Consider orientation changes (portrait/landscape)

**Layout Adaptations:**
- **Mobile (< 768px):** Single column, stacked content
- **Tablet Portrait (768px):** Two columns possible
- **Tablet Landscape (1024px):** Three columns, desktop-like
- **Desktop (1280px+):** Full layouts, maximum content

**Recommendation for Ami Sushi:**
- **Primary Design:** 1024px iPad landscape (main presentation view)
- **Secondary:** 768px tablet portrait (fallback)
- **Tertiary:** Mobile portrait for reference/sharing
- Use CSS Grid or Flexbox for flexible layouts
- Test all transitions between breakpoints

### 7.2 Performance Considerations with Images

#### Image Optimization Strategies

**File Format Selection:**
- **WebP:** Best compression, modern browser support (use with fallbacks)
- **JPEG:** Photographs and complex images
- **PNG:** Graphics requiring transparency, simple illustrations
- **SVG:** Logos, icons, simple graphics (infinitely scalable)

**Responsive Images:**
```html
<picture>
  <source media="(min-width: 1024px)" srcset="image-large.webp">
  <source media="(min-width: 768px)" srcset="image-medium.webp">

</picture>
```

**Lazy Loading:**
- Load images as they enter viewport
- Reduces initial page load time
- Essential for presentation with many slides
- Native browser support: `loading="lazy"`

**Image Sizing Guidelines:**
- Serve images at display size (don't scale down large images)
- Use 2x resolution for Retina displays (but compress well)
- Full-bleed images: 2048px wide maximum
- Card/contained images: Match container size

**Compression:**
- Use tools like ImageOptim, TinyPNG, Squoosh
- Target: < 200KB per full-screen image
- Balance quality vs. file size
- Test on actual devices

**Recommendation for Ami Sushi:**

### 7.3 CSS/Framer Motion Animation Patterns

#### Framer Motion Overview
Production-ready motion library for React with powerful capabilities for presentations.

**Core Animation Features:**

**1. Spring Physics vs. Duration-Based:**
- Physical properties (x, scale): Spring physics (natural movement)
- Visual properties (opacity, color): Duration-based easing
- Choose based on property type for best feel

**2. Page Transitions:**
- AnimatePresence API for slide transitions
- Smooth entry/exit animations
- Custom transition effects
- Prevents abrupt element removal

**3. Hardware Acceleration:**
- Intelligently uses GPU for smooth performance
- Hardware acceleration for transform properties
- Ensures 60fps animations
- Optimized for mobile/tablet devices

**4. Scroll-Linked Animations:**
- Use scroll position to drive animations
- Parallax effects
- Reveal animations
- Progress-based transitions

**Sources:**
- [Framer Motion - Animation Documentation](https://www.framer.com/motion/animation/)
- [Framer Motion - Transition Guide](https://www.framer.com/motion/transition/)
- [NUMI - 10 Framer Motion Examples](https://www.numi.tech/post/framer-motion-examples)

#### Animation Best Practices for Presentations

**Performance Optimization:**

**1. LazyMotion for Bundle Size:**
- Load motion features asynchronously
- Only include necessary animation capabilities
- Reduces initial bundle size
- Critical for fast presentation loading

**2. Animation Triggers:**
- Set `once: true` for animations that should only play once
- Prevents repetitive animations
- Improves performance
- Better user experience

**3. Optimize Animation Properties:**
- Prefer `transform` and `opacity` (GPU accelerated)
- Avoid animating `width`, `height`, `top`, `left`
- Use `scale` instead of width/height
- Use `translate` instead of position

**Recommended Animation Patterns:**

**Slide Transitions:**
```typescript
// Subtle slide fade
const slideVariants = {
  enter: { opacity: 0, x: 20 },
  center: { opacity: 1, x: 0 },
  exit: { opacity: 0, x: -20 }
};

// Smooth transition
const transition = {
  duration: 0.4,
  ease: [0.25, 0.1, 0.25, 1] // Custom bezier
};
```

**Element Reveals:**
```typescript
// Stagger children
const containerVariants = {
  hidden: { opacity: 0 },
  show: {
    opacity: 1,
    transition: {
      staggerChildren: 0.1
    }
  }
};
```

**Scroll-Based:**
```typescript
// Parallax effect
const { scrollYProgress } = useScroll();
const y = useTransform(scrollYProgress, [0, 1], [0, -100]);
```

**Recommendation for Ami Sushi:**
- **Slide transitions:** Subtle fade + slight horizontal movement (0.4s)
- **Element reveals:** Stagger animation for lists/grids (0.1s delay)
- **Image loads:** Fade in with slight scale (0.6s)
- **Scroll effects:** Parallax for background images (subtle)
- **Interactive elements:** Smooth hover states (0.2s)
- Use LazyMotion to reduce bundle size
- Set animations to play once
- Test on actual iPad hardware for smoothness

### 7.4 Accessibility with Creative Layouts

#### WCAG Contrast Requirements

**Level AA Compliance (Target):**
- **Normal text:** Minimum 4.5:1 contrast ratio
- **Large text:** Minimum 3:1 contrast ratio
  - Large = 14pt bold (18.66px) or 18pt regular (24px)

**Level AAA Compliance (Ideal):**
- **Normal text:** Minimum 7:1 contrast ratio
- **Large text:** Minimum 4.5:1 contrast ratio

**Non-Text Elements (WCAG 2.1):**
- UI components: Minimum 3:1 against adjacent colors
- Graphical objects: Minimum 3:1
- Icons, buttons, form inputs

   - Limited palette (3 main + 2 accents)
   - Accents used sparingly for emphasis
   - Deep, sophisticated tones over bright colors

4. **Story-Driven Structure:**
   - Clear narrative arc from start to finish
   - Each slide serves the overall story
   - Emotional pacing and logical flow

5. **Full-Bleed for Impact, Contained for Information:**
   - Hero moments use full-bleed imagery
   - Content slides use asymmetric layouts
   - Mix patterns for visual rhythm

6. **Subtle, Purposeful Animation:**
   - Enhance, don't distract
   - Smooth transitions (0.4-0.5s)
   - Respect reduced motion preferences

7. **Mobile-Responsive Design:**
   - Primary: iPad landscape (1024px)
   - Test across breakpoints
   - Maintain experience on all devices

8. **Accessibility as Standard:**
   - Not an afterthought
   - WCAG AA minimum for all elements
   - Test with real assistive technology

### 10.2 What Makes a Presentation Feel Modern vs. Dated

#### Modern Presentations:
- Dark mode or sophisticated neutrals
- Bold, oversized typography
- Generous whitespace
- Full-bleed imagery
- Subtle animations
- Story-driven structure
- Mobile-responsive
- Accessible by design
- Minimal text per slide
- Professional photography

#### Dated Presentations:
- Bright, primary colors
- Gradient backgrounds (2000s style)
- Bullet point heavy
- Small, contained images
- Clipart or stock photos
- Generic templates
- Text-heavy slides
- Flashy transitions
- Desktop-only design
- Low-quality images
