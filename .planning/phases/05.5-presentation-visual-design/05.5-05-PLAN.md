<task type="auto">
  <name>Task 2: Accessibility and Performance Audit</name>
  <files>components/presentation/layouts/*.tsx, app/globals.css</files>
  <action>
    Ensure WCAG compliance and smooth performance:

    **1. Color contrast verification:**

    For each layout component, verify text contrast:
    - White text on image overlays: minimum 4.5:1 (use 60%+ opacity overlays)
    - Cream (washi) on dark backgrounds: verify sufficient contrast
    - Gold (kincha) accent text: only use at large sizes (minimum 3:1)

    Add fallback for low-contrast situations:
    ```css
    .text-overlay {
      /* Ensure readability with text shadow fallback */
      text-shadow: 0 1px 3px rgba(0, 0, 0, 0.5);
    }
    ```

    **2. Reduced motion support:**

    In all layout components, wrap animations with:
    ```typescript
    const prefersReducedMotion = useReducedMotion()

    // In motion components:
    <motion.div
      initial={prefersReducedMotion ? false : { opacity: 0 }}
      animate={{ opacity: 1 }}
      transition={prefersReducedMotion ? { duration: 0 } : { duration: 0.5 }}
    />
    ```

    Add to globals.css:
    ```css
    @media (prefers-reduced-motion: reduce) {
      *, ::before, ::after {
        animation-duration: 0.01ms !important;
        animation-iteration-count: 1 !important;
        transition-duration: 0.01ms !important;
        scroll-behavior: auto !important;
      }
    }
    ```

    **3. Focus indicators:**

    Ensure all interactive elements have visible focus states:
    ```css
    .interactive-element:focus-visible {
      outline: 2px solid var(--color-kincha);
      outline-offset: 4px;
    }
    ```

    **4. Keyboard navigation:**

    Verify:
    - Left/Right arrow keys navigate slides
    - Tab key moves through interactive elements
    - Enter/Space activates buttons and links
    - Escape key doesn't break anything

    **5. Performance checks:**

    Image optimization verification:
    - All images should be under 200KB (ideally <150KB)
    - Use Next.js Image component with proper sizing
    - Lazy load all images except first slide

    Animation performance:
    - Use `transform` and `opacity` only (GPU accelerated)
    - Avoid animating `width`, `height`, `margin`, `padding`
    - Test on lower-powered devices if possible

    Add will-change hints for frequently animated elements:
    ```css
    .slide-content {
      will-change: transform, opacity;
    }
    ```
  </action>
  <verify>
    - Run browser DevTools Lighthouse accessibility audit
    - Check console for any contrast warnings
    - Enable "Reduce motion" in OS settings, verify animations disabled
    - Navigate entire presentation using only keyboard
    - Check Network tab - images loading efficiently
    - Check Performance tab - animations at 60fps
  </verify>
  <done>
    - All text meets WCAG AA contrast (4.5:1 minimum)
    - Reduced motion preference respected
    - Focus indicators visible on all interactive elements
    - Keyboard navigation works throughout
    - Images optimized and lazy loaded
    - Animations GPU-accelerated and smooth
  </done>
</task>
