<task type="auto">
  <name>Task 1: Fix Content Truncation in SlideContainer</name>
  <files>components/presentation/SlideContainer.tsx, app/page.tsx</files>
  <action>
    Modify SlideContainer.tsx to prevent content truncation:

    1. Change the content container from fixed height centering to flexible layout:
       - Replace `h-full flex items-center justify-center` pattern
       - Use `min-h-full flex flex-col justify-center` instead
       - Add `overflow-y-auto` when content exceeds viewport

    2. Update padding strategy:
       - Current: `pt-20 pb-20` is too aggressive
       - New: `pt-16 pb-16` with responsive variants `md:pt-20 md:pb-24`
       - Add safe area insets for mobile: `pb-safe`

    3. Add a new prop `autoScroll?: boolean` (default: true) that:
       - Enables vertical overflow scrolling for tall content
       - Shows subtle scroll indicator when content overflows
       - Maintains `overflow-hidden` for slides that fit

    4. Update app/page.tsx inner content wrapper:
       - Change from `h-full flex items-center justify-center px-12 md:px-24`
       - To: `min-h-full flex items-center py-8 px-8 md:px-16 lg:px-24`
       - This allows content to grow naturally instead of being squeezed

    Key constraint: Do NOT change animation transitions or slide navigation behavior.

    Why these changes: The current implementation uses absolute centering which clips content that exceeds container height. Flex with min-height allows natural content flow while maintaining visual centering for smaller content.
  </action>
