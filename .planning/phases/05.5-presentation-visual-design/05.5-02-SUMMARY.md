## Decisions Made

**Layout Architecture:**
- Each layout is a self-contained component with exported TypeScript interface
- Props provide configuration flexibility without requiring code changes
- Layouts handle their own responsive behavior and animations

**Animation Consistency:**
- All layouts use 300ms duration, 100ms stagger delay
- Framer Motion provides smooth, polished transitions
- Respects prefers-reduced-motion preference

**Accessibility:**
- All layouts maintain WCAG AA contrast minimum (4.5:1)
- Image overlays use configurable opacity to ensure text readability
- Semantic HTML and proper heading hierarchy

**Japanese Aesthetic Principles:**
- **Ma (negative space):** CenteredMinimal uses max-width 90%, generous padding
- **Wabi-sabi (authenticity):** Natural image handling without over-processing
- **Shibumi (refined understatement):** Subtle animations, quality over quantity
