Create Timeline component using pattern from 04-RESEARCH.md (Pattern 2: Custom Flexbox Timeline).

**Timeline.tsx structure:**
- Accept `weeks: Array<{title: string, items: string[]}>` prop
- Use flexbox layout with vertical center line (absolute positioned div with w-0.5 bg-brand-red)
- Each week entry: relative positioning with timeline dot (left-[-2rem], w-4 h-4 rounded-full bg-brand-red ring-4 ring-white)
- Content: h3 for week title (text-xl font-bold mb-2), ul for items (space-y-1 text-base text-gray-300)
- Framer Motion: motion.div wrapping each week with whileInView={{opacity: 1, x: 0}} initial={{opacity: 0, x: -20}} transition={{delay: i * 0.15, duration: 0.4}} viewport={{once: true}}
- Styling: pl-8 for content offset from timeline, gap-8 between weeks

**index.ts:**
- Export Timeline from barrel: `export { Timeline } from './Timeline'`

**Why flexbox + CSS (not library):** This is presentation graphic, not data dashboard. Custom CSS keeps bundle size minimal and gives full control over animation timing. Research confirmed this approach for static timelines.

**Color scheme:** Use brand-red (#b22222) for timeline line and dots, white ring around dots for contrast, gray-300 for item text. Matches existing brand colors from tailwind.config.js.

**Animation timing:** 150ms stagger delay between weeks (i * 0.15), 400ms transition duration. Research recommends 100-150ms stagger for smooth sequential reveal without feeling slow.
