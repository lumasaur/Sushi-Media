Modify app/page.tsx to add staggered entry animations to bullet lists using Framer Motion variants pattern from 04-RESEARCH.md (Pattern 1: Staggered Entry Animation).

**Add variant definitions (after imports, before component):**
```typescript
const containerVariants = {
  hidden: { opacity: 0 },
  visible: {
    opacity: 1,
    transition: {
      staggerChildren: 0.15,  // 150ms delay between bullets
      delayChildren: 0.2       // Initial delay before first bullet
    }
  }
}

const itemVariants = {
  hidden: { opacity: 0, x: -20 },
  visible: { opacity: 1, x: 0, transition: { duration: 0.4 } }
}
```

**Update content layout bullet rendering:**

Replace static `<ul>` with `<motion.ul>`:
```typescript
<motion.ul
  variants={containerVariants}
  initial="hidden"
  animate="visible"
  className="space-y-4 text-lg md:text-xl"
>
  {slide.bullets.map((bullet, i) => (
    <motion.li
      key={i}
      variants={itemVariants}
      className="flex items-start"
    >
      <span className="text-brand-red mr-3 mt-1">•</span>
      {typeof bullet === 'string' ? (
        <span>{bullet}</span>
      ) : (
        <div>
          <div>{bullet.main}</div>
          <ul className="mt-2 ml-4 space-y-1 text-base md:text-lg text-gray-300">
            {bullet.sub.map((subBullet, j) => (
              <li key={j} className="flex items-start">
                <span className="text-brand-red mr-2">◦</span>
                <span>{subBullet}</span>
              </li>
            ))}
          </ul>
        </div>
      )}
    </motion.li>
  ))}
</motion.ul>
```

**Why these timings:** Research recommends 100-150ms stagger delays for smooth sequential reveal. 150ms is sweet spot: fast enough to feel responsive, slow enough to be noticeable. 200ms initial delay allows slide title to settle before bullets animate. 400ms transition duration (0.4s) creates smooth, polished motion per Nielsen Norman Group guidelines (200-500ms range).

**Important:** This applies to 'content' layout only. Do NOT change timeline or systems layouts - those components handle their own animations. CTA layout keeps static rendering (no animation needed for final action slide).

**Import motion:** Already imported from 'framer-motion', but verify: `import { motion } from 'framer-motion'`

**Sub-bullets:** Keep static rendering for sub-bullets (no nested stagger) to avoid animation fatigue. Main bullets provide visual rhythm; sub-bullets are supporting detail.
