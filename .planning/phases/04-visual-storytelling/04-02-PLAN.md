Create SystemDiagram component using pattern from 04-RESEARCH.md (Pattern 4: System Diagram with Arrows).

**SystemDiagram.tsx structure:**
- Accept `systems: Array<{icon: string, title: string, description: string}>` prop
- Use flexbox layout: `flex items-center justify-center gap-4 md:gap-8`
- Three boxes: each with `bg-brand-black border-2 border-brand-red rounded-lg p-6 flex-1 max-w-xs`
- Between boxes: ArrowRight icon from lucide-react with `w-6 h-6 text-brand-red flex-shrink-0`
- Each box contains: Icon (w-12 h-12 text-brand-red mb-4), h3 (font-bold text-xl mb-2), p (text-gray-300 text-base)
- Framer Motion: motion.div wrapping each box with whileInView={{opacity: 1, scale: 1}} initial={{opacity: 0, scale: 0.8}} transition={{delay: i * 0.2}} viewport={{once: true}}
- Icon mapping: Use Users (Social Media), Calendar (Corporate Lunch), TrendingUp (Weekday Bar) from lucide-react

**Why this layout:** Horizontal flow shows linear progression A → B → C with feedback loop concept. ArrowRight icons create visual connection. Staggered scale animation (0.8 to 1.0) creates "pop-in" effect that draws attention to each system sequentially.

**Responsive strategy:** On mobile, boxes may stack if screen too narrow. Use `flex-wrap: wrap` with `justify-center` to allow graceful degradation. Arrows become vertical separators visually when boxes wrap.

**Color scheme:** Black boxes with red borders create premium feel. Red icons provide visual anchors. Gray text for descriptions maintains hierarchy (title > description).

**Animation timing:** 200ms delay between boxes (i * 0.2), creating smooth 1-2-3 reveal. Longer delay than timeline (200ms vs 150ms) because fewer elements need more emphasis.

**Import icons individually (NOT dynamic):** `import { Users, Calendar, TrendingUp, ArrowRight } from 'lucide-react'` - Research warns against lucide-react/dynamic for bundle bloat. Individual imports enable tree-shaking.

Create IconWithLabel component using pattern from 04-RESEARCH.md (Pattern 3: Icon-Based Visual Hierarchy).

**IconWithLabel.tsx structure:**
- Accept `icon: LucideIcon, title: string, description: string, className?: string` props
- Import `LucideIcon` type from lucide-react for type safety
- Layout: `flex items-start gap-4`
- Icon: Pass as prop, render with `w-8 h-8 text-brand-red flex-shrink-0 mt-1` and `strokeWidth={2}` for prominence, `aria-hidden="true"` for accessibility
- Content div: h3 with title (text-xl font-bold mb-2), p with description (text-gray-300)
- Allow className override for flexibility: `className={cn('flex items-start gap-4', className)}`

**Why this pattern:** Reusable component for adding icons to any content section. Icons provide visual anchors that help users scan and remember key points. Research confirms icons improve information hierarchy and retention.

**Icon sizing:** w-8 h-8 (32px) is large enough to be recognizable but doesn't overwhelm text. mt-1 offset aligns icon with text baseline. strokeWidth={2} makes icon bolder for better visibility.

**Accessibility:** aria-hidden="true" because icon is decorative - title/description provide semantic meaning. Icon enhances visual hierarchy but isn't required to understand content.

**Use case:** This component can be used in system deep dive slides (3-5) to add visual interest to bullet points. Example: IconWithLabel with TrendingUp icon for "Revenue opportunity" sections.

**TypeScript:** Import `import { LucideIcon } from 'lucide-react'` for icon prop type. This allows any Lucide icon to be passed as prop while maintaining type safety.
