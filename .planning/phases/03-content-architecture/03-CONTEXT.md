Visual polish, animations, and advanced graphics are Phase 4. This phase establishes the content structure and text.

<decisions>
## Implementation Decisions

### Slide Structure
- **Organization:** Overview + deep dives (one slide introduces all 3 systems, then separate slides for each system's details)
- **Slides per system:** Claude decides based on content complexity
- **Section headers:** Yes — show breadcrumb-style context like "Three Systems > Social Media Engine" on each slide
- **Target count:** 8-10 slides
- **Timeline:** First 30 Days gets its own slide; skip February calendar (timeline detail is enough)
- **"Empty Hours" placement:** Slide 2, immediately after title (hook them early)
- **Final slide:** Summary (recap Three Systems names) + two CTAs

### Content Density
- **Bullets per slide:** 4-6 main bullets, or 3-4 if using sub-bullets
- **Sub-bullet treatment:** Indented + smaller text for clear hierarchy
- **Bullet length:** Short and punchy (5-10 words per bullet, no full sentences)
- **Headlines:** Action-oriented verbs ("Capture Empty Hours" / "Drive Weekday Traffic")
- **Metrics:** Directional only — avoid specific numbers/commitments ("significant revenue" not "$X")
- **Overview slide:** Three Systems with names + one-liner each
- **Title slide:** Just "Premium Sushi with Social Soul" — clean, single message
- **Empty Hours slide:** Just the hook, no supporting context

### Narrative Flow
- **Arc:** Problem → Solution → Action (classic pitch structure)
- **System relationship:** Reinforcing loop / flywheel (show how each system feeds the others)
- **Tone:** Confident and direct ("We know what works, here's the plan")
- **Risks:** Brief acknowledgment — one line showing awareness, quickly pivot to solutions

### Deep Dive Format
- **Emphasis:** Problem + System solution (the gap this system fills and how it fills it)
- **Platform specificity:** Category only ("Social platforms" not "Instagram, TikTok")
- **Flywheel connection:** Implied only — focus on the system itself, flywheel understood from overview
- **Visual structure:** Similar with variation (same bones, content drives minor layout differences)

### Timeline Slide (First 30 Days)
- **Timing format:** Relative (Week 1, Week 2, etc.) — works regardless of start date
- **Detail level:** High-level milestones only ("Week 1: Launch social presence")

### Final Slide (Next Steps)
- **Structure:** Summary + CTAs
- **Summary content:** Recap Three Systems names
- **CTA treatment:** Two clear paths side-by-side

### Claude's Discretion
- Exact slide count within 8-10 range
- How many slides per system deep dive
- Specific bullet wording
- How to visually show flywheel relationship in overview
- Section header visual treatment
- Transition language between slides

</decisions>
