**Interface:**

```typescript
interface UseTouchGesturesOptions {
  onNavigateForward: () => void
  onNavigateBackward: () => void
  doubleTapThreshold?: number  // ms, default 600 per CONTEXT.md
  swipeThreshold?: number      // px, default 100 per CONTEXT.md
  angleThreshold?: number      // degrees, default 30 per CONTEXT.md
  enabled?: boolean            // default true
}
```

**Double-Tap Logic (per CONTEXT.md - 600ms threshold):**
```typescript
// Track last tap time and position
const lastTapRef = useRef<{ time: number; x: number; y: number } | null>(null)

const handleTouchEnd = (e: TouchEvent) => {
  const touch = e.changedTouches[0]
  const now = Date.now()
  const lastTap = lastTapRef.current

  // Check for double-tap
  if (lastTap &&
      now - lastTap.time < doubleTapThreshold &&
      Math.abs(touch.clientX - lastTap.x) < 30 &&  // Same spot tolerance
      Math.abs(touch.clientY - lastTap.y) < 30) {

    // Double-tap detected - determine zone
    const screenWidth = window.innerWidth
    const tapX = touch.clientX

    if (tapX < screenWidth * 0.25) {
      onNavigateBackward()
      triggerHaptic()
    } else {
      onNavigateForward()
      triggerHaptic()
    }

    lastTapRef.current = null  // Reset after double-tap
  } else {
    lastTapRef.current = { time: now, x: touch.clientX, y: touch.clientY }
  }
}
```

**Haptic Feedback:**
```typescript
const triggerHaptic = () => {
  if ('vibrate' in navigator) {
    navigator.vibrate(10)  // Subtle 10ms vibration
  }
}
```

Add swipe detection with angle detection to distinguish from scrolling:

**Swipe Logic (per CONTEXT.md - 100-150px threshold, 30 degree angle):**
```typescript
const touchStartRef = useRef<{ x: number; y: number; time: number } | null>(null)

const handleTouchStart = (e: TouchEvent) => {
  const touch = e.touches[0]
  touchStartRef.current = {
    x: touch.clientX,
    y: touch.clientY,
    time: Date.now()
  }
}

const handleTouchEnd = (e: TouchEvent) => {
  const touchStart = touchStartRef.current
  if (!touchStart) return

  const touch = e.changedTouches[0]
  const deltaX = touch.clientX - touchStart.x
  const deltaY = touch.clientY - touchStart.y
  const elapsed = Date.now() - touchStart.time

  // Calculate angle from horizontal
  const angle = Math.abs(Math.atan2(deltaY, deltaX) * (180 / Math.PI))
  const isHorizontal = angle < angleThreshold || angle > (180 - angleThreshold)

  // Swipe detection: horizontal, sufficient distance, reasonable time
  if (isHorizontal && Math.abs(deltaX) > swipeThreshold && elapsed < 500) {
    if (deltaX < 0) {
      // Swipe left = go forward
      onNavigateForward()
      triggerHaptic()
    } else {
      // Swipe right = go back
      onNavigateBackward()
      triggerHaptic()
    }
  }

  touchStartRef.current = null
}
```

**Important:** This runs BEFORE double-tap check in the same handler. Structure the handler to check swipe first (if distance > threshold), otherwise check double-tap.

Add logic to detect when touch is on scrollable content and adjust behavior:

**Scrollable Content Detection:**
```typescript
const isOnScrollableContent = (target: EventTarget | null): boolean => {
  if (!(target instanceof HTMLElement)) return false

  // Check if target or any parent has scrollable-slide class
  const scrollableParent = target.closest('.scrollable-slide')
  if (!scrollableParent) return false

  // Check if content actually overflows (needs scrolling)
  return scrollableParent.scrollHeight > scrollableParent.clientHeight
}
```

**Behavior Modification:**
When touch starts on scrollable content:
- Double-tap still works normally (always allow navigation via double-tap)
- Vertical swipes do NOT trigger navigation (let content scroll)
