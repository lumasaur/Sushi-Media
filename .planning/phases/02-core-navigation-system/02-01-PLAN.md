  <action>
Create `hooks/useSlideNavigation.ts` with the following:

**Interface:**
```typescript
interface UseSlideNavigationOptions {
  totalSlides: number
  initialSlide?: number  // defaults to 0 or hash value
}

interface UseSlideNavigationReturn {
  currentSlide: number
  nextSlide: () => void
  previousSlide: () => void
  goToSlide: (index: number) => void
  isFirst: boolean
  isLast: boolean
}
```

**URL Hash State (per CONTEXT.md decisions):**
- Read initial slide from `window.location.hash` (e.g., `#3` -> slide 3)
- Parse hash as 1-indexed for human readability (URL shows #1, internally slide 0)
- Invalid hash values (NaN, out of range) redirect to slide 0
- Forward navigation (`nextSlide`) creates new history entry via `history.pushState`
- Backward navigation (`previousSlide`) uses existing history (no new entry)
- `goToSlide` creates history entry (like forward navigation)
- Listen to `popstate` event for browser back/forward button support

**Keyboard Navigation (per CONTEXT.md decisions):**
- Forward: Right Arrow, Down Arrow, Spacebar, Page Down, Enter
- Backward: Left Arrow, Up Arrow, Page Up, Backspace
- Jump to first: Home key
- Jump to last: End key
- Focus management: Skip keyboard nav when `document.activeElement` is input/textarea/select

**Implementation Notes:**
- Use `useEffect` for event listeners with proper cleanup
- Use `useCallback` for stable function references
- Handle SSR by checking `typeof window !== 'undefined'`
- Wrap initial hash read in useEffect (not during render) to avoid hydration mismatch

Create `hooks/index.ts` barrel file exporting the hook.

  <action>
Add `popstate` event listener to sync state with browser navigation:

```typescript
useEffect(() => {
  const handlePopState = () => {
    const hash = window.location.hash.slice(1)
    const slideNum = parseInt(hash, 10)
    if (!isNaN(slideNum) && slideNum >= 1 && slideNum <= totalSlides) {
      setCurrentSlide(slideNum - 1)  // Convert 1-indexed URL to 0-indexed state
    } else {
      setCurrentSlide(0)
    }
  }

  window.addEventListener('popstate', handlePopState)
  return () => window.removeEventListener('popstate', handlePopState)
}, [totalSlides])
```

**History Entry Logic:**
- `nextSlide`: `history.pushState(null, '', `#${currentSlide + 2}`)` (creates entry)
- `previousSlide`: Just update state, don't push (uses existing history)
- `goToSlide`: `history.pushState(null, '', `#${targetSlide + 1}`)` (creates entry)

This ensures:
- Forward navigation builds history stack
- Back button returns to previous slides
- Forward button returns to where you were
